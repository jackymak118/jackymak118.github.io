Personal Google Calendar Bridge

This page describes the OAuth client ID used by my personal desktop AI assistant ("Hermes") to integrate with my own Google account.

Single-user personal application. This app is not offered to the public. It is operated solely for the owner's own personal use and does not process, collect, sell, or share data on behalf of any third party.

Purpose

The app requests access to the owner's Google Calendar and Contacts so that the desktop assistant can read schedule, create events, and check availability on the owner's behalf, all within the same local session.

Scopes requested

  • auth/calendar — read and write the owner's calendar
  • auth/contacts.readonly — read contacts for attendee lookup

Privacy policy

No personal data is stored on any server. All API calls are made locally from the owner's own machine using the owner's own credentials. No information is transmitted to, processed by, or shared with any third party. Token credentials never leave the owner's device.

Terms of service

This is a single-user personal integration with no public user base. There are no user-facing terms beyond Google's own Terms of Service and OAuth scope consent. The app does not collect, retain, or monetize user data in any form.

Owner-operated. Not a public application. No analytics, no tracking, no third-party access.
